# سرور اعلان Push (اختیاری، ولی لازم برای اعلان با برنامه‌ی کاملاً بسته)

## چرا اصلاً به یک سرور نیاز است؟
این یک محدودیت فنی مرورگرهاست، نه چیزی که بشود دور زد: وقتی برنامه/تب کاملاً
بسته می‌شود، هیچ کد جاوااسکریپتی دیگر در حال اجرا نیست تا تاریخ چک‌ها را چک
کند و تصمیم بگیرد الان زمان اعلان است یا نه. تنها راهی که مرورگر بتواند وقتی
برنامه بسته است اعلان نشان دهد، این است که یک سرور جداگانه (که همیشه روشن
است) هر چند دقیقه چک کند و پیام Push واقعی بفرستد — دقیقاً همان کاری که
اپ‌های نیتیو اندروید هم پشت صحنه با Firebase Cloud Messaging انجام می‌دهند.
یعنی این «دردسر» مخصوص این برنامه نیست؛ هر برنامه‌ای (نیتیو یا وب) که بخواهد
با برنامه‌ی کاملاً بسته اعلان بدهد، به یک سرور پشت صحنه نیاز دارد.

خبر خوب: این Worker همان سرور را برایتان از قبل نوشته، و یک روش کاملاً بدون
ترمینال (فقط با کلیک و مرورگر) برای راه‌اندازی‌اش هست — مرحله «۱. بدون
ترمینال» را ببینید. مجموعاً حدود ۵ دقیقه زمان می‌برد و کاملاً رایگان است، و
فقط یک‌بار لازم است انجام شود.

بدون این سرور هم برنامه کار می‌کند و اعلان‌های واقعی مرورگر (نه فقط toast)
نمایش داده می‌شوند، اما فقط تا وقتی مرورگر/برنامه در پس‌زمینه در حال اجراست؛
اگر کاربر برنامه را به‌طور کامل ببندد (force stop)، بدون این سرور اعلانی
نمی‌رسد.

## روش ۱ (پیشنهادی، بدون ترمینال، ~۵ دقیقه)

### الف) دیپلوی با یک کلیک
1. این ریپو را روی گیت‌هاب خودتان Push کنید (اگر هنوز نکرده‌اید).
2. این لینک را در مرورگر باز کنید (به‌جای `YOUR_GITHUB_REPO_URL` آدرس ریپوی
   خودتان را بگذارید):
   ```
   https://deploy.workers.cloudflare.com/?url=YOUR_GITHUB_REPO_URL
   ```
   یا دکمه زیر را به README گیت‌هابتان اضافه کنید تا همیشه در دسترس باشد:
   ```
   [![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=YOUR_GITHUB_REPO_URL)
   ```
3. با حساب Cloudflare (رایگان) وارد شوید یا بسازید. Cloudflare به‌صورت خودکار
   یک کپی از ریپو در حساب خودتان می‌سازد، پایگاه داده KV لازم را می‌سازد و
   Worker را دیپلوی می‌کند.
4. در پایان یک آدرس شبیه این می‌گیرید — همین را نگه دارید:
   ```
   https://check-reminder-zare-push.YOUR_SUBDOMAIN.workers.dev
   ```

### ب) ساخت کلیدهای VAPID (بدون ترمینال)
یکی از این ابزارهای رایگان را باز کنید (کلیدها کاملاً در همان مرورگر شما
ساخته می‌شوند و به هیچ سروری فرستاده نمی‌شوند):
- https://randomkeygen.com/vapid-key
- https://knock.app/tools/vapid-key-generator

دو مقدار `Public Key` و `Private Key` را کپی و جایی نگه دارید.

### پ) وارد کردن Secret ها از داشبورد Cloudflare (بدون ترمینال)
1. وارد داشبورد Cloudflare شوید → **Workers & Pages** → روی Worker جدیدتان
   (مثلاً `check-reminder-zare-push`) کلیک کنید.
2. به تب **Settings → Variables and Secrets** بروید.
3. سه مقدار زیر را با دکمه «Add» اضافه کنید و هرکدام را روی حالت
   **Encrypt/Secret** بگذارید:
   - `VAPID_PUBLIC_KEY` = همان Public Key مرحله قبل
   - `VAPID_PRIVATE_KEY` = همان Private Key مرحله قبل
   - `VAPID_SUBJECT` = چیزی مثل `mailto:you@example.com`
4. اگر می‌خواهید اعلان ایمیل هم فعال شود، `RESEND_API_KEY` را هم همین‌جا
   اضافه کنید (توضیح در بخش ۷ پایین همین فایل).
5. روی **Save and deploy** بزنید.

### ت) اتصال برنامه به سرور
1. برنامه چک یاداور زارع را باز کنید → تنظیمات
2. در بخش «اعلان Push واقعی»:
   - آدرس سرور اعلان: همان آدرس workers.dev بالا
   - کلید عمومی VAPID: همان Public Key
3. روی «اتصال اعلان Push» بزنید و اجازه اعلان را در مرورگر تایید کنید.

از این پس، هر بار که چکی اضافه/ویرایش/حذف کنید یا تنظیمات را عوض کنید،
برنامه به‌صورت خودکار اطلاعات را با سرور همگام می‌کند و سرور در زمان مقرر
اعلان واقعی ارسال می‌کند — حتی اگر برنامه کاملاً بسته باشد.

## روش ۲ (با ترمینال، برای کسانی که به CLI راحت‌ترند)

### ۱. نصب ابزار Wrangler
```bash
npm install -g wrangler
wrangler login
```

### ۲. ساخت پایگاه داده KV
```bash
cd worker
npx wrangler kv namespace create CHECK_REMINDERS_KV
```
خروجی چیزی شبیه این می‌دهد:
```
{ binding = "CHECK_REMINDERS_KV", id = "abcd1234..." }
```
مقدار `id` را کپی کنید و در فایل `wrangler.toml` به جای
`REPLACE_WITH_YOUR_KV_NAMESPACE_ID` قرار دهید.

### ۳. ساخت کلیدهای VAPID
```bash
npx web-push generate-vapid-keys
```
دو مقدار `Public Key` و `Private Key` را نگه دارید.

### ۴. تنظیم Secret ها
```bash
npx wrangler secret put VAPID_PUBLIC_KEY
npx wrangler secret put VAPID_PRIVATE_KEY
npx wrangler secret put VAPID_SUBJECT
# برای VAPID_SUBJECT چیزی مثل: mailto:you@example.com وارد کنید
```

### ۵. دیپلوی
```bash
npx wrangler deploy
```

سپس همان مرحله «ت» بالا (اتصال برنامه به سرور) را انجام دهید.

## تست سریع
می‌توانید با درخواست زیر یک اعلان تستی بفرستید (subscription را از
DevTools → Application → Service Workers → Push کپی کنید، یا بعد از اتصال
از طریق برنامه امتحان کنید):
```bash
curl -X POST https://YOUR_WORKER_URL/api/test-push \
  -H "Content-Type: application/json" \
  -d '{"subscription": { ... }}'
```

## نکات
- این Worker کاملاً روی پلن رایگان Cloudflare (KV + Cron Triggers) جواب می‌دهد.
- هر ۵ دقیقه یک‌بار اجرا می‌شود؛ یعنی اعلان‌ها ممکن است تا حداکثر چند دقیقه
  با زمان دقیق تنظیم‌شده اختلاف داشته باشند.
- اگر برنامه به‌صورت محلی یا در WebView اندروید اجرا می‌شود، لازم نیست تغییری در
  آدرس Worker بدهید — فقط این Worker جداگانه به‌عنوان «سرور اعلان» به آن وصل می‌شود.

## ۷. اعلان از طریق ایمیل (اختیاری)
اگر می‌خواهید یادآوری چک‌ها علاوه بر گوشی، به ایمیل (مثلاً جیمیل) هم ارسال شود:

1. در [resend.com](https://resend.com) با همان ایمیلی که می‌خواهید یادآوری‌ها را
   دریافت کنید، یک حساب رایگان بسازید (نیازی به دامنه یا تنظیمات DNS نیست).
2. از داشبورد Resend یک API Key بسازید.
3. آن را به‌عنوان Secret اضافه کنید — یا از داشبورد Cloudflare (مرحله «پ» بالا،
   بدون ترمینال)، یا با ترمینال:
   ```bash
   npx wrangler secret put RESEND_API_KEY
   ```
4. برنامه چک یاداور زارع را باز کنید → تنظیمات → بخش «اعلان از طریق ایمیل» →
   همان ایمیلی که با آن در Resend ثبت‌نام کردید را وارد کنید.

توجه: در پلن رایگان Resend، بدون تایید دامنه، فقط می‌توانید به همان ایمیلی که
با آن ثبت‌نام کرده‌اید ایمیل بفرستید — که برای این برنامه (تک‌کاربره) دقیقاً
همین کافی است.
